# Расписание 10-х классов

Бот расписания уроков для 10а и 10б (I смена). Каждый выбирает свой класс и профиль:

| Класс | Профиль | id |
|---|---|---|
| 10а | социально-экономический («сэ») | `se` |
| 10а | технологический («тех») | `tech` |
| 10б | естественно-научный («ен») | `en` |
| 10б | гуманитарный («гум») | `gum` |

Работает на **Telegram Serverless** (app8734400455), Mini App — <https://app8734400455.tgcloud.ai/>.

## Что умеет

| Команда / кнопка | Что делает |
|---|---|
| `/start` | при первом запуске — выбор класса |
| `/class`, «🏫 Класс» | сменить класс и профиль |
| `/today`, «📅 Сегодня» | уроки на сегодня: время, кабинет, что идёт сейчас |
| `/tomorrow`, «➡️ Завтра» | уроки на завтра |
| `/week`, «🗓 Неделя» | неделя (в выходные — следующая) |
| `/bells`, «🔔 Звонки» | расписание звонков |
| `/dz`, «📝 Задания» | ДЗ и заметки своего класса |
| `/dz мат: №5–10` | записать ДЗ к ближайшему уроку по предмету |
| `/note хим: формулы` | заметка к предмету |

Класс запоминается для чата: в личке — свой, в группе класса — один на всю группу.
Mini App берёт класс из лички с ботом, и наоборот: смена класса в приложении меняет его и в боте.
Задания и заметки у каждого профиля свои. Время — якутское (UTC+9).

## Деплой

Ключ (@BotFather → бот → Serverless → CLI Access) лежит в `.tgcloud/credentials` (не в git)
или в переменной `TGCLOUD_TOKEN_SCHOOL`.

```sh
npm test
npm run deploy     # сборка Mini App → tgcloud push → migrate --safe
```

После деплоя напиши боту `/start` — он выставит меню команд, кнопку «Расписание» и описание.

## Как поменять расписание

Всё в `tgcloud/lib/school.js`:

- `BELLS` — звонки, `YEAR_START` / `YEAR_END` — учебный год.
- `DAYS` — строки таблицы по дням: `row(n, …)`, где
  `a(предмет, каб.)` — урок для всего 10а, `b(…)` — для всего 10б,
  `split([сэ], [тех], [ен], [гум])` — у профилей разные уроки (`null` — урока нет).
  Третий элемент `'база'` — базовый уровень («(Б)» в таблице).

## Где что лежит

```

  lib/school.js         — РАСПИСАНИЕ (правь здесь)
  lib/schedule.js       — даты, уроки класса, тексты ответов
  lib/bot.js            — команды, кнопки, выбор класса
  lib/homework.js       — ДЗ: поиск предмета, ближайший урок
  lib/notes.js, prefs.js — база: задания и выбранный класс
  handlers/             — message, callback_query
  endpoints/            — для Mini App: listNotes, addNote, deleteNote, getClass, setClass
  schema.js             — таблицы notes и chats
webapp/                 — Mini App (index.html, style.css, app.js)
scripts/build.mjs       — сборка Mini App в dist/
scripts/deploy.mjs      — деплой
test/school.test.js     — тесты
```
