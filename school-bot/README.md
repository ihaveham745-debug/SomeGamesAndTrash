# Расписание 10-х классов

Бот расписания уроков для 10а и 10б (I смена).

10а и 10б — классы, сэ / тех / ен / гум — профильные группы, в которых смешаны ученики обоих
классов. В таблице белые ячейки — урок всего класса, серые — урок профильной группы.
Поэтому каждый выбирает **класс и профиль** (8 вариантов, `a-se` … `b-gum`): общие уроки
берутся из колонки класса, профильные — из колонки профиля.

| Профиль | |
|---|---|
| сэ | социально-экономический |
| тех | технологический |
| ен | естественно-научный |
| гум | гуманитарный |

Работает на **Telegram Serverless** (app8734400455), Mini App — <https://app8734400455.tgcloud.ai/>.

## Что умеет

| Команда / кнопка | Что делает |
|---|---|
| `/start` | при первом запуске — выбор класса и профиля |
| `/class`, «класс» | сменить класс и профиль |
| `/today`, «сегодня» | уроки на сегодня: время, кабинет, что идёт сейчас |
| `/tomorrow`, «завтра» | уроки на завтра |
| `/week`, «неделя» | неделя (в выходные — следующая) |
| `/bells`, «звонки» | расписание звонков |
| `/dz`, «задания» | ДЗ и заметки своего класса |
| `/dz мат: №5–10` | записать ДЗ к ближайшему уроку по предмету |
| `/note хим: формулы` | заметка к предмету |

Класс запоминается для чата: в личке — свой, в группе класса — один на всю группу.
Mini App берёт класс из лички с ботом, и наоборот: смена класса в приложении меняет его и в боте.
ДЗ к профильному уроку видит вся профильная группа (из обоих классов), к общему — весь класс. Время — якутское (UTC+9).

## Деплой

Ключ (@BotFather → бот → Serverless → CLI Access) лежит в `.tgcloud/credentials` (не в git)
или в переменной `TGCLOUD_TOKEN_SCHOOL`.

```sh
npm test
npm run deploy     # сборка Mini App → tgcloud push → migrate --safe
```

После деплоя напиши боту `/start` — он выставит меню команд, кнопку «Расписание» и описание.

## Как поменять расписание

Всё в `tgcloud/lib/school.js`:

- `BELLS` — звонки, `YEAR_START` / `YEAR_END` — учебный год.
- `ROWS` — строки таблицы по дням: `row(n, …)`, где
  `A(предмет, каб.)` / `B(…)` — белая ячейка, урок всего 10а / 10б;
  `P('en gum', …)` — серая ячейка на несколько профилей;
  `S([сэ], [тех], [ен], [гум])` — серые ячейки, у каждого профиля своё (`null` — урока нет).
  Последний элемент `'база'` — базовый уровень («(Б)» в таблице).

## Файлы к дз

К записи можно прикрепить одно фото или файл (до 10 мб из приложения).

- в чате: пришли фото/файл с подписью `/dz мат: текст` (или `/my …`, `/note …`); текст после двоеточия можно не писать;
- в приложении: «прикрепить файл» в окне записи. Фото открывается превью, любой файл бот пришлёт в чат кнопкой «в чат»;
- под `/dz` и расписанием дня — кнопки «фото — предмет дата»: бот присылает файл в этот чат.

Своего хранилища нет: файл лежит в Telegram, в базе — `file_id` (`lib/files.js`). Чтобы получить `file_id`
файла из приложения, бот на секунду отправляет его человеку в личку и удаляет сообщение.
Кто видит файл — так же, как запись: класс, профильная группа или только автор.

## Обои

Кнопка «обои» в приложении — у каждого свои, другим ничего не меняется: котики, «стекло» или своё фото
из галереи. Фото приложение уменьшает до 1280 px и отправляет боту (в Telegram, в базе — `file_id`,
таблица `wallpapers`), выбор одинаковый на всех устройствах. Своё фото получить может только его хозяин
(`wallpaperImage` отдаёт обои того, кто спрашивает). Своё фото можно удалить кнопкой с корзиной (`deleteWallpaper`) — тогда снова котики.

## Напоминания о дз

Каждый сам включает себе напоминание о конкретном дз — бот напишет в личку.
День — любой, время — одно из четырёх: 9:00, 15:00, 18:00 или 0:00 (по Якутску).

- в приложении: колокольчик у дз (жёлтый — включено) → день в календаре и время; или «напомнить …» в окне записи;
- в чате: под ответом на `/dz` — «напомнить накануне: 9:00 / 15:00 / 18:00 / в 0:00» (0:00 — полночь перед уроком)
  и «напомнить в другой день» (открывает приложение сразу на этом дз).

Своего расписания у платформы нет, поэтому рассылку (`lib/reminders.js`, `sendDueReminders`) запускают:
- попутно — каждое сообщение боту, нажатие кнопки, открытие приложения;
- по часам — GitHub Actions раз в 10 минут (`.github/workflows/school-reminders.yml` → `endpoints/remindTick`).
  Для этого нужен секрет `TGCLOUD_TOKEN_SCHOOL` в настройках репозитория, а файл workflow — в ветке по умолчанию.

Все тексты бота и приложения — строчными и без эмодзи (то, что пишут сами ученики, остаётся как есть).
