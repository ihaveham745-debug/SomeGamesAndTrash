# debt-bot — тетрадка долгов

Telegram-бот на Telegram Serverless: записываешь, кому дал в долг, бот считает, кто сколько должен.

## Как пользоваться

- Дал в долг — напиши боту: `Петя 500`, `Петя 1500 кино`, `Маша 2к`.
- Вернули: `Петя вернул 200` или `Петя -200` (часть), `Петя вернул` (всё).
- **💰 Мне должны** — список и итог. Нажми на друга: история, «✅ вернул всё», «↩️ вернул часть»,
  «➕ дал ещё», «🔔 напомнить», «↩️ отменить последнее», «🗑 удалить».
- **🔗 Ссылка для друга** — друг открывает её и подключается: видит свой долг («🙈 Я должен»),
  получает напоминания и записи о новых долгах, может нажать «💸 я вернул» — владелец подтверждает.

Тетрадка у каждого своя: бот работает только в личке, чужие записи не видны.

## Код

```
tgcloud/
  schema.js          — users, friends (друзья в тетрадке), ops (записи: дал / вернули, в копейках)
  lib/money.js       — суммы, даты, разбор «Петя 500 пицца»
  lib/app.js         — вся логика: сообщения, кнопки, тексты (без sdk — проверяется тестами)
  lib/store.js       — база
  lib/telegram.js    — связка с sdk
  handlers/message.js, handlers/callback_query.js
test/bot.test.js     — разбор записей и сценарии на базе в памяти
```

`npm test` — тесты, `npm run deploy` — выложить (ключ `app…:…` в `.tgcloud/credentials`, не в git).
