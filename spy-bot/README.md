# Шпион — игра в Telegram

У всех игроков одно общее слово (место, еда, животное…) — кроме шпиона. Два режима:

- **другое слово** (по умолчанию) — у шпиона другое слово той же темы, и он сам не знает, что он шпион;
- **шпион без слова** — шпион знает, что он шпион, но слова не знает (с подсказкой — знает тему)
  и может раскрыться и угадать слово.

Telegram Serverless: app8801791786, Mini App — <https://app8801791786.tgcloud.ai/>.

## Как играть

**В группе.** Добавь бота в чат и напиши `/spy`:

1. лобби: «✋ играю» — войти/выйти; ведущий 👑 настраивает тему, число шпионов, режим и жмёт «▶️ начать» (от 3 игроков);
2. каждый жмёт «🎭 моя роль» — Telegram показывает всплывающее окно только ему;
3. игроки по очереди задают вопросы (бот называет, кто начинает);
4. голосование — кнопками с именами (можно передумать). Когда проголосовали все или ведущий нажал «📊 итоги»:
   больше всех голосов у шпиона — победа мирных, иначе (или ничья) — победа шпиона;
5. в режиме «без слова» шпион может раскрыться — «🕵️ я шпион — угадать слово» — и выбрать слово из 8 вариантов: угадал — победа шпиона;
6. «🔁 ещё раз» — новая партия с теми же игроками.

`/stop` — отменить игру (ведущий), `/rules` — правила.

**С одного телефона** — в приложении: число игроков (3–20), шпионов, категория, подсказка, таймер;
телефон передают по кругу, каждый смотрит свою роль, потом обсуждение с таймером и «показать шпиона».

## Устройство

```
tgcloud/
  lib/words.js          — категории и слова
  lib/game.js           — правила: лобби, роли, голосование, угадывание (без sdk — и для бота, и для приложения)
  lib/bot.js            — сообщение игры и кнопки, разбор нажатий (press)
  lib/store.js          — игры в базе: одна на чат, сохранение с проверкой версии
  handlers/message.js   — /spy, /stop, /rules, /start
  handlers/callback_query.js — нажатия кнопок игры
  schema.js             — таблица games
webapp/                 — приложение «один телефон»
test/spy.test.js        — тесты
```

## Деплой

Ключ (@BotFather → бот → Serverless → CLI Access) — в `.tgcloud/credentials` (не в git) или `TGCLOUD_TOKEN_SPY`.

```sh
npm test
npm run deploy
```

После деплоя напиши боту `/start` в личке — он выставит меню команд, кнопку «играть» и описание.
