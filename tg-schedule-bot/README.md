# Пары на сегодня — боты расписания групп ФТИ

Один код — несколько ботов, у каждой группы свой:

| Группа | Бот | Файл расписания |
|---|---|---|
| Б-ЭО-26 | [@For_Milian_bot](https://t.me/For_Milian_bot) | `tgcloud/lib/groups/b-eo-26.js` |
| Б-ТММС-26 | [@Rentonchik666_pro_bot](https://t.me/Rentonchik666_pro_bot) | `tgcloud/lib/groups/b-tmms-26.js` |

Бот показывает пары на сегодня, на завтра и на неделю, а ещё говорит, чётная сейчас неделя
или нечётная.

Работает на **Telegram Serverless**: код лежит в облаке Telegram, свой сервер не нужен.
Есть и **Mini App** — приложение с расписанием прямо внутри Telegram
(<https://app8605454352.tgcloud.ai/>).

## Что умеет

| Команда / кнопка | Что делает |
|---|---|
| `/today`, «📅 Сегодня» | пары на сегодня + номер и чётность недели |
| `/tomorrow`, «➡️ Завтра» | пары на завтра |
| `/week`, «🗓 Неделя» | расписание на текущую неделю |
| `/parity`, «🔢 Чётность» | чётная или нечётная неделя |
| `/dz`, «📝 Задания» | домашние задания (с сегодняшнего дня) и заметки группы |
| `/dz мат: №5–10` | записать ДЗ к ближайшей паре по предмету |
| `/note хим: формулы на стр. 12` | заметка к предмету (без даты) |

Предмет можно писать коротко: по началу слова (`мат`, `хим`, `рус`), по первым буквам
(`орг`, `сцт`, `ия`) или по-студенчески (`физра`, `англ`). Задания и заметки общие для всей
группы и видны у пар в расписании — и в боте, и в приложении. Удалить запись может только
тот, кто её добавил (в приложении, кнопкой 🗑).

### Замена аудитории

Аудитория поменялась — её может поправить любой в группе, и все увидят новую:

- в приложении: нажми на аудиторию у пары → новая аудитория → «только в этот день» или «всегда»
  (каждую неделю по этому дню). «Вернуть как в расписании» — убрать замену;
- в чате: `/aud 2 305` — 2-я пара сегодня, `/aud 24.10 3 228 КФЕН` — на дату,
  `/aud 2 305 всегда` — каждую неделю, `/aud 2 сброс` — вернуть как было.

Изменённая аудитория подсвечена, старая — зачёркнута (в боте: «305 (вместо 214)»).

### Пары не будет

Отменить пару на один день — видят все в группе:

- в приложении: нажми на аудиторию у пары → «Пары не будет»; вернуть — там же «Пара будет — вернуть»
- в чате: `/cancel 5` — 5-я пара сегодня, `/cancel 28.10 5` — на дату, `/cancel 28.10 5 вернуть` — пара будет.

Отменённая пара зачёркнута, с пометкой «пары не будет». В базе это замена аудитории с пустой
аудиторией (`CANCELLED` в `lib/schedule.js`).
Замены хранятся в базе (таблица `rooms`, `lib/rooms.js`), само расписание в файле группы не меняется.

У каждой пары — время, аудитория и преподаватель. В расписании на сегодня бот пишет,
что идёт сейчас (или через сколько следующая пара), и отмечает «окна» между парами.

Под расписанием есть кнопки: ◀️ ▶️ листают дни (воскресенье пропускается) и недели,
«🗓 Вся неделя» и кнопки дней переключают вид, «🔄 Обновить» пересчитывает «что сейчас».
Сообщение меняется на месте, чат не засоряется.

### Mini App

Вкладки «День», «Неделя» и «Задания». На карточке пары — её ДЗ и кнопка «+ ДЗ»;
во вкладке «Задания» — все задания по датам и заметки по предметам.

В личке с ботом слева от поля ввода есть кнопка **«Расписание»** — она открывает приложение:
полоска дней недели, карточки пар с временем, аудиторией и преподавателем, «что идёт сейчас»
с полоской прогресса (обновляется само), вкладка «Неделя». Дни листаются свайпом,
недели — стрелками или свайпом по полоске дней. Оформление — «жидкое стекло» в духе iOS 26:
полупрозрачные панели над цветным фоном, плавающий таб-бар, перетекающие выделения.
Светлая или тёмная версия — по теме Telegram, акцентный цвет — цвет кнопок из темы.
Если в системе включено «Понижение прозрачности» или «Уменьшение движения», стекло
становится плотным, а анимации выключаются.

Расписание у бота и приложения общее: при сборке `tgcloud/lib/schedule.js` и `timetable.js`
копируются в приложение как есть, править их надо в одном месте.

«Сегодня» считается по времени Якутска (UTC+9).

## Как задеплоить

Нужен Node.js 18+. Для каждого бота: @BotFather → бот → **Serverless** → включить →
**CLI Access** → скопировать *Access token* (начинается с `app…`, это **не** токен бота).

```sh
npm install
TGCLOUD_TOKEN_B_TMMS_26=app… npm run deploy -- b-tmms-26   # первый раз — с ключом
npm run deploy -- b-tmms-26                                # дальше ключ уже сохранён
```

Имя переменной — `TGCLOUD_TOKEN_` + группа большими буквами (`TGCLOUD_TOKEN_B_EO_26`).
Скрипт собирает копию проекта для группы в `.deploy/<группа>/` (там же хранит ключ,
папка не попадает в git), заливает код и Mini App и применяет безопасные изменения базы.
Ключ от чужого бота он не примет — расписание одной группы не уедет в бота другой.

После деплоя напиши боту `/start` — он выставит себе меню команд, кнопку «Расписание» и описание.

После любых правок расписания снова запусти `npm run deploy -- <группа>`.

### Новая группа

1. Скопируй `tgcloud/lib/groups/b-eo-26.js` в `tgcloud/lib/groups/<группа>.js`, поменяй
   `GROUP`, `APP_ID` (из ключа: `app<цифры>`), `MINI_APP_URL` и само расписание.
2. `npm test` — проверит, что пары попадают в звонки и нет накладок.
3. `TGCLOUD_TOKEN_<ГРУППА>=app… npm run deploy -- <группа>`.

## Как поменять расписание

Всё в файле группы, `tgcloud/lib/groups/<группа>.js`:

- `SEMESTER_START` — неделя, в которую попадает эта дата, считается 1-й (нечётной).
  Если в вузе неделя считается наоборот, сдвинь дату на неделю.
- `SEMESTER_END` — после этой даты бот скажет, что семестр закончился.
- `TIMETABLE` — пары по дням (1 = понедельник … 7 = воскресенье). У пары есть поля:
  `n` (номер), `subject`, `type`, `teacher`, `room`, необязательные
  `week: 'odd'` / `week: 'even'` (только нечётные / чётные недели) и `until: 'ГГГГ-ММ-ДД'`
  (последний день, когда пара ещё есть).

В исходной таблице `*` означает нечётную неделю, `**` — чётную.
